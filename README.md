# Between the Covers

A responsive book discovery website built as part of the Frontend Phase 1 Capstone.

## Project Goals

- Browse books using the Open Library API.
- Search books by title.
- Save and remove favorite books.
- Persist favorites using browser localStorage.
- Navigate between Home, Favorites, and About pages.

## Technologies

- HTML5
- Tailwind CSS v4
- Vanilla JavaScript with ES modules
- Vite
- Open Library Search API
- Git and GitHub

## Development Plan

- Lab 4: GitHub collaboration and project tracking
- Lab 1: Responsive multi-page layouts
- Lab 2: DOM interactivity and favorites
- Lab 3: Asynchronous JavaScript and API integration
